# QUE ES ESTO

skus_excluidos_intencionales

Este es un sistema en python con streamlit que sirve para optimizar el inventario de una empresa, se conecta a la base de datos de la empresa y extrae los datos de los productos y sus ventas, luego aplica un modelo matemático del punto de reorden para calcular el inventario óptimo y muestra los resultados en gráficos y tablas, adicionalmente tiene otras funciones como el calculo de la rotacion de inventario, el punto de reorden, el nivel de servicio, la cantidad economica de pedido, el tiempo economico de reposicion, el costo de mantenimiento de inventario, el costo de pedido, el costo de rotura de stock, el costo total de inventario, el costo de oportunidad, el rendimiento antes de impuestos sobre la inversion, el diferencial cambiario BCV y Binance, el indice de precios al consumidor de Venezuela, el producto interno bruto per capita de Venezuela, el producto interno bruto per capita de Colombia, el diferencial cambiario BCV y Binance, el indice de precios al consumidor de Venezuela, el producto interno bruto per capita de Venezuela, el producto interno bruto per capita de Colombia, el diferencial cambiario BCV y Binance, el indice de precios al consumidor de Venezuela, el producto interno bruto per capita de Venezuela, el producto interno bruto per capita de Colombia
